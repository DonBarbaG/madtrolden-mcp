# Security pass (spec §9) — verified 2026-08-03

- [x] **No secret, key, or example real key in repo or git history.** `git log --all -p | grep -E "troll_[a-z2-7]{26}"` finds only the `.env.example` line explicitly labeled "NOT a real key". Real keys exist only in Vercel env (encrypted) and the owner's local `.env.local` (gitignored).
- [x] **ACCESS_KEYS parsing rejects malformed entries loudly.** Empty var, missing separator, bad name, malformed key, stray comma, duplicate name — all throw with position-based messages that never echo key material (unit-tested in `lib/http/auth.test.ts`).
- [x] **Timing-safe comparison; uniform 401; no key material in errors or logs.** Candidate and stored keys are compared as SHA-256 digests via `crypto.timingSafeEqual`; every configured key is checked on every attempt (no early exit). 401 body and headers identical for missing/malformed/wrong keys. Logs carry account names and 8-char SHA-256 fingerprints only.
- [x] **Rate limits actually return 429.** Verified live against the deployment (12×429 in a 70-request burst) and unit-tested (`lib/http/rate-limit.test.ts`), with `Retry-After` set.
- [x] **No persistence.** No db/kv/blob client in `package.json` dependencies (`redis` appears only as a transitive dep of mcp-handler 1.x's SSE path, which is disabled and never invoked). The only `fs.writeFile` is the stdio-mode file backend, unreachable in HTTP mode (guarded by account context; sentinel-tested in `lib/tools/profile.test.ts`).
- [x] **All outbound calls go only to documented hosts.** Fetch targets in code: `api.etilbudsavis.dk`, `api.dataforsyningen.dk`. (Other URLs in the repo are recipe-credit strings and README links, never fetched. Frida/DTU is downloaded at build time only, by `scripts/build-nutrition.py` on a dev machine.)
- [x] **CORS / surface.** The MCP endpoint adds no permissive CORS headers; unauthenticated callers get a uniform 401 and learn nothing. Landing page is static with zero data and no endpoint enumeration.
- [x] **npm audit** — 5 findings (1 low, 4 high), all in `sharp`/libvips, a transitive optional dependency of Next.js used exclusively by `next/image` image optimization, which this project does not use (no `next/image` imports; the only page is static text). The suggested "fix" downgrades Next to v9 and is nonsensical. Accepted as a documented exception; revisit when Next ships an updated sharp.
- [x] **Attribution present** for tilbudstrolden (MIT, LICENSE kept), Tjek/eTilbudsavis, Frida/DTU (CC BY 4.0 + DOI), DAWA — in README.md, landing page, and tool outputs (nutrition/geo lines).
